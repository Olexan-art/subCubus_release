# SUBCUBUS — завантаження

**SUBCUBUS** — програма для Windows: конвертер відео, студія субтитрів і перекладу з локальним ШІ, монтаж звуку з вимірюванням гучності (LUFS) і робоче місце дубляжу. Працює на вашому комп’ютері, без хмари.

## Завантажити

Остання версія — на сторінці **[Releases](../../releases/latest)**:

| Файл | Для чого |
|---|---|
| `SUBCUBUS-Setup-<версія>.exe` | Інсталятор. Рекомендовано: ярлик, асоціація файлів, оновлення з програми |
| `SUBCUBUS-Portable-<версія>.exe` | Портативна версія: без встановлення, можна запускати з флешки |

Встановлену програму можна оновлювати з неї самої: коли виходить нова версія, вгорі вікна з’являється кнопка **«Оновлення»**.

## Вимоги

- Windows 10 або 11, 64-біт
- 8 ГБ оперативної пам’яті (для перекладу вбудованим ШІ — від 8 ГБ; моделі 12B — 16 ГБ або відеокарта з 8 ГБ)
- Моделі ШІ (переклад, розпізнавання мовлення й голосів) завантажуються з програми окремо, один раз

> Файли не підписані цифровим сертифікатом, тому під час першого запуску Windows SmartScreen може показати попередження: «Докладніше» → «Однаково запустити».

## Що вміє

- **Звукорежисерам:** монтаж звуку під відео, еквалайзер, компресор, лімітер, шумозаглушення, індикатори рівня, гучність у LUFS і доведення до стандарту (ТБ −23, YouTube −14, подкаст −16, кіно −27 LUFS)
- **Перекладачам субтитрів:** оригінал і переклад поруч, переклад і підказки локальним ШІ, перевірка русизмів, читабельності (CPS), термінологія
- **Дабберам:** ролі й сценарій, запис дублів точно в таймінг, вибір і прийняття дубля, лист реплік, експорт ролей у WAV
- **Відео:** конвертація будь-яких форматів, вшивання субтитрів, збірка відео, кількох звукових доріжок і субтитрів в один файл

## Сторонні компоненти та ліцензії

Також використано: Electron (MIT), React (MIT), llama.cpp / node-llama-cpp (MIT), whisper.cpp (MIT, через фільтр FFmpeg), ONNX Runtime (MIT), tesseract.js (Apache 2.0), JASSUB / libass (MIT, ISC).
